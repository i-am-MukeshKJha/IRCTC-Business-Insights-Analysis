
# IRCTC Business Insights Dashboard | Power BI

## Project Overview

This project presents an interactive Business Insights Dashboard
developed using Microsoft Power BI to analyze railway booking
performance and business metrics.

The dashboard provides a visual overview of booking trends,
revenue performance, booking statuses, and other key indicators.

## Objectives

- Monitor key booking and revenue metrics.
- Analyze booking trends over time.
- Compare booking statuses and categories.
- Explore performance using interactive slicers and filters.
- Present business information through an interactive dashboard.

## Tools & Technologies

- Microsoft Power BI
- Power Query for data preparation
- DAX for measures and calculations
- Data visualization and interactive reporting

## Dashboard Features

- KPI cards for key business metrics
- Booking trend analysis
- Booking status breakdown using donut charts
- Horizontal bar charts for comparisons
- Interactive slicers and filter panel
- Business-focused dashboard layout and navigation


## How to Use

1. Download the Power BI report (.pbix) from this repository.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, configure the data source using the
   authorized dataset included with the project.
4. Refresh the data if required.
5. Explore the dashboard using its slicers, charts, and filters.

## Key Learnings

- Designing interactive Power BI dashboards
- Presenting KPIs and business trends
- Creating visual comparisons
- Building user-friendly report navigation
- Communicating insights through data visualization
